# Jurnal - Copilot Instructions

React Native/Expo journaling app with TypeScript + TailwindCSS (via uniwind).

## Commands

```bash
# Development
yarn dev                 # Start Expo dev server (clears cache)
yarn android            # Run on Android
yarn ios                # Run on iOS

# Quality checks
yarn typecheck          # TypeScript validation
yarn lint               # ESLint
yarn format             # Prettier

# Build
yarn prebuild           # Generate native directories
yarn android:build      # Local Android build (EAS)
yarn ios:build          # Local iOS build (EAS)
```

**Testing:** No test suite configured yet.

**Pre-commit:** Runs `tsc --noEmit` on staged TS files + `lint-staged` (Prettier + ESLint with `--max-warnings 0`).

## Architecture

### Navigation Hierarchy

```
Navigation (top-level container)
  └── TabBar (bottom tabs)
        └── Views (stack navigators)
              └── Screens (wrapped in BaseScreen)
```

- **Views** (`src/view/`): Stack navigators grouping related screens. Platform-specific animations (iOS: `ios_from_right`, Android: `fade`).
- **Screens** (`src/screen/`): Always wrapped in `BaseScreen` for consistent safe area handling and layout. Pass `as="scroll"` or `as="view"`.
- **Navigation types**: Defined in `src/type/navigation.ts` (e.g., `HomeStackParamList`).

### Data Flow

**Server State:**

- TanStack Query with 60s stale time (`src/config/client.ts`)
- Axios client in `src/api/axios.ts` with interceptors:
  - Request: logs API calls via `apiLog.debug`
  - Response: validates `{code, message}` structure, throws AxiosError if `code !== 200`
  - Error: logs via `apiLog.warn` and re-throws

**Client State:**

- Zustand configured in `src/store/store.ts` (currently unused)

### Environment & Config

- **Environment variants:** `app.config.ts` modifies app name/package based on `EXPO_PUBLIC_ENVIRONMENT` (appends `.development` suffix for non-production).
- **Node requirement:** >= 22 (enforced in `package.json`).

## Code Conventions

### Component Structure

One component per file, default export. Use function declarations for components, arrow functions for utilities.

**Hook order** (from `src/.github/instructions/component-architecture.md`):

1. Hook (e.g., `useNavigation()`)
2. Global state (Zustand)
3. State (`useState`)
4. Reference (`useRef`)
5. API (`useQuery`)
6. Memo (`useMemo`, `useDerivedValue`, `useStyle`)
7. Callback (`useCallback`)
8. Imperative handle
9. Method (plain functions)
10. Effect (`useEffect`)
11. Render

### Naming

- **Components/files**: PascalCase (`HomeScreen.tsx`)
- **Utility files**: kebab-case (`api-client.ts`)
- **Variables**: camelCase
- **Constants**: UPPER_SNAKE_CASE
- **Types**: PascalCase, use `type` not `interface`

### Styling

- **TailwindCSS via uniwind**: Use className prop on React Native components.
- **Class merging**: Use `clx()` helper from `src/util/util.ts` (wraps `twMerge`) for conditional classes.
- **Global styles**: Modify `src/global.css` for Tailwind imports.
- **Config**: Extend via `tailwind.config.js`.

### TypeScript

- Strict mode enabled with `useUnknownInCatchVariables`
- Type definitions: `src/type/`
- Use `type` keyword, not `interface`

### Logging

**Never use `console.log`** - ESLint treats console statements as errors.
Use loggers from `src/util/logger.ts`:

- `apiLog.debug()` / `apiLog.warn()` for API-related logs
- Import other loggers as needed

### Code Style

- Line length: 100 chars
- Indent: 2 spaces
- Quotes: single
- Semicolons: required
- Trailing commas: all
- Arrow function parens: avoid when single param
- JSX: self-closing tags required

## Guardrails

### Never Touch

- `.expo/`, `android/`, `ios/` (build outputs, regenerated by `expo prebuild`)

### Require Review Before Modifying

- Navigation structure or API contracts
- Native dependency additions/modifications
- `app.config.ts`, `app.json`, `babel.config.js`

## Key Files

- `src/App.tsx`: Main app entry, wraps Navigation with providers
- `src/component/navigation/Navigation.tsx`: Top-level navigation container
- `src/component/navigation/BaseScreen.tsx`: Screen wrapper with safe area insets
- `src/api/axios.ts`: Axios client with interceptors
- `src/config/client.ts`: TanStack Query client configuration
- `src/util/util.ts`: Shared utilities (`clx`, `sleep`)
- `src/util/logger.ts`: Logging utilities
- `app.config.ts`: Expo config with environment-based variants
